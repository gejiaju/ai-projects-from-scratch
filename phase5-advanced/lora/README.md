# 第五阶段 · LoRA 大模型微调

> 大模型（LLM）几百亿参数，全量微调需要几十张 A100。LoRA 的妙处是：**只训练一个小矩阵**，
> 就能让模型学会新任务，普通显卡也能跑。这是当前大模型应用最核心的技术之一。

## LoRA 原理（一句话）

大模型微调时，参数的更新量其实很低秩（不需要改所有方向）。所以 LoRA 不直接更新原权重 W，
而是加一个"旁路"：`W' = W + ΔW = W + B·A`，其中 A、B 是两个小矩阵（秩 r 很小，比如 8）。
训练时冻结 W，只更新 A 和 B。这样参数量从 `d×d` 降到 `2×d×r`，能省上千倍。

## 面试自述要点

"我做了个 LoRA 微调：用 Qwen2.5 小模型，微调数据是电子信息考研面试问答。核心理解是——
LoRA 利用'参数更新是低秩的'这个性质，冻结原模型，只训练旁路的两个小矩阵 A 和 B，
把微调成本从全量参数降到千分之一。`print_trainable_parameters()` 打印出来能看到，
可训练参数只占百分之零点几。这个技术让'个人玩家微调大模型'从不可能变成可能。"

## 面试追问准备

- **为什么 LoRA 有效？** 大模型预训练后已经学到通用知识，微调只是"小范围调整"，
  更新量天然低秩，所以用低秩矩阵就能近似。
- **r（秩）怎么选？** r 越大表达能力越强但参数越多，常用 8~64。任务越难、和预训练
  差异越大，r 要大一点。
- **和全量微调比？** LoRA 参数少、快、省显存，精度略低于全量微调但差距很小，
  是性价比最高的方案。
- **target_modules 为什么选注意力层？** 注意力层是模型"学知识"最集中的地方，
  只微调这些层就能覆盖大部分微调收益。
