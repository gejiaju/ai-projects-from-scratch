# YOLOv8 结构解析（Backbone / Neck / Head）

> 本文基于本机 ultralytics 8.4.95 源码里的 `cfg/models/v8/yolov8.yaml` 和
> `nn/modules` 的 Conv / C2f / SPPF / Detect 定义整理。可用 `inspect_yolov8.py` 复现。

## 一、一句话总览

YOLOv8 做检测分三步：

```
输入图片 640×640×3
   │
   ▼
Backbone（主干）——从图片里提取特征，逐层缩小尺寸、加深语义
   │  输出 3 个尺度的特征图：P3(80×80)  P4(40×40)  P5(20×20)
   ▼
Neck（颈部）——把 3 个尺度的特征互相融合，让大目标和小目标都看得清
   │
   ▼
Head（检测头）——在每个尺度上预测"框在哪 + 是什么类别"
```

## 二、Backbone：提取特征

Backbone 是 CSPDarknet 风格，由 **Conv**、**C2f**、**SPPF** 三种模块堆叠而成，
用步长为 2 的卷积逐步下采样（尺寸减半、通道翻倍）。

真实结构（取自 yolov8.yaml 的 backbone 段）：

| 层 | 模块 | 输出尺寸 | 输出通道 |
|----|------|---------|---------|
| 0 | Conv(3→64, s2) | 320×320 | 64 |
| 1 | Conv(64→128, s2) | 160×160 | 128 |
| 2 | C2f ×3 | 160×160 | 128 |
| 3 | Conv(128→256, s2) | **80×80** | 256 |
| 4 | C2f ×6 | 80×80 | 256 |
| 5 | Conv(256→512, s2) | **40×40** | 512 |
| 6 | C2f ×6 | 40×40 | 512 |
| 7 | Conv(512→1024, s2) | **20×20** | 1024 |
| 8 | C2f ×3 | 20×20 | 1024 |
| 9 | SPPF | 20×20 | 1024 |

三个关键模块：

- **Conv** = 卷积 Conv2d + 批归一化 BatchNorm + SiLU 激活函数。源码里 `forward`
  就是 `self.act(self.bn(self.conv(x)))` 一行。
- **C2f** = YOLOv8 的**创新点**（替代 YOLOv5 的 C3）：把输入拆成两半，一半直接
  传到输出，另一半经过 n 个 Bottleneck 再拼接。好处是**保留更多梯度信息、更轻量**。
- **SPPF**（Spatial Pyramid Pooling Fast）：对同一特征图做多次 5×5 最大池化再拼接，
  **用很小的计算量扩大了感受野**（相当于同时看到 5×5、9×9、13×13 的范围），
  对小目标检测有帮助。

## 三、Neck：融合多尺度特征

Neck 是 **PAN-FPN** 结构，让"浅层的细节"和"深层的语义"互相补充：

- **FPN 方向（自顶向下）**：把高层的语义信息通过上采样传给低层，让小目标也能
  借到大目标的"全局上下文"。
- **PAN 方向（自底向上）**：再把低层的细节（边缘、位置）通过下采样传回高层，
  让大目标的**定位更准**。

最终 Neck 输出三个尺度的特征图：

| 输出 | 尺寸 | 负责检测的目标 |
|------|------|--------------|
| P3 | 80×80（stride 8） | 小目标 |
| P4 | 40×40（stride 16） | 中等目标 |
| P5 | 20×20（stride 32） | 大目标 |

> 这就是"多尺度检测"：同一张图用三个不同分辨率的网格分别预测，小目标在高分辨率
> 网格（80×80）上更清楚，大目标在低分辨率网格（20×20）上感受野更大。

## 四、Head：anchor-free 解耦头

Head 里的 **Detect** 模块做两件事（这是 YOLOv8 相比前代的两大改动）：

1. **Anchor-free（无锚框）**：不再预设一堆不同大小的"锚框"，而是直接回归目标的
   **中心点坐标和宽高**。省去了锚框超参数，泛化更好。
2. **解耦（Decoupled）**：分类分支和回归分支**分开**。以前的 YOLO 分类和定位共用
   一个输出，现在拆开，两个分支各学各的，收敛更快。

每个网格点输出：`4（框坐标） + nc（类别数）` 个数，在三个尺度上分别预测，
最后用 NMS（非极大值抑制）去掉重复框。

## 五、输入输出维度总结

```
输入: [B, 3, 640, 640]
        ↓ Backbone
P3: [B, 256, 80, 80]   ← 小目标
P4: [B, 512, 40, 40]   ← 中目标
P5: [B, 1024, 20, 20]  ← 大目标
        ↓ Neck (PAN-FPN 融合)
        ↓ Head (Detect, anchor-free 解耦)
输出: 每尺度 [B, 4+nc, H, W] 个预测框 → NMS → 最终检测结果
```

> 注：上面通道数是 `scale=l`（yolov8l）的数值；`yolov8n` 会按 width 因子 0.25 缩放，
> 结构不变、通道更少，所以更轻更快（315 万参数，8.9 GFLOPS）。
