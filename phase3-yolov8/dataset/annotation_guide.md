# 用 LabelImg 自建数据集（标注指南）

> 目标检测的训练数据 = **图片 + 标注**。标注就是"告诉模型：这张图里，哪个框里是什么东西"。
> 这一步是第三阶段的重中之重——数据质量直接决定模型上限。

## 一、准备

1. **装 LabelImg**（图形化标注工具，在 Windows 上双击就能用）：

   ```bash
   pip install labelimg
   labelImg
   ```

2. **准备图片**：建两个文件夹
   ```
   mydata/
     images/      ← 把要标注的照片放这里
     labels/      ← 标注结果会自动生成到这里
   ```

## 二、标注步骤

1. 打开 LabelImg → 左侧 **Open Dir** 选 `images` 文件夹
2. 左侧 **Change Save Dir** 选 `labels` 文件夹
3. 左侧格式选 **YOLO**（重要！不是 PascalVOC）
4. 按 **W** 键 → 鼠标拖出一个框把目标框住 → 输入类别名 → 确定
5. 一张图里所有目标都框完 → 按 **D** 键下一张

## 三、标注规则（数据质量的关键）

- **框要贴边**：框的边界尽量贴着目标轮廓，不要留大空边，也不要切掉目标
- **目标被遮挡**：只框"看得到"的部分
- **太小太糊的目标**：如果自己都认不出来，跳过——标注不确定的坏样本比不标更糟
- **类别要一致**：同类目标永远用同一个类别名（"person" 别一会儿写 person 一会儿写 people）

## 四、标注文件长什么样（YOLO 格式）

每张图生成一个同名 `.txt`，每行一个目标：

```
0 0.523456 0.412345 0.123456 0.234567
1 0.765432 0.654321 0.098765 0.187654
```

- 第 1 个数：类别编号（0 = 你的 names 列表里的第一个类）
- 第 2、3 个数：框的**中心点**坐标（归一化到 0~1，是相对图片宽高的比例）
- 第 4、5 个数：框的**宽和高**（同样归一化到 0~1）

## 五、训练前的检查

标注完，先跑一遍 `prepare_dataset.py` 检查有没有漏标、类别越界：

```bash
cd /mnt/f/yolo/phase3-yolov8/dataset
python3 prepare_dataset.py --root mydata
```

看到"缺少标注的图片: 0"就可以开始训练了。

## 六、经验谈（面试可讲）

> "我一开始标注了 200 张，训练出来模型乱检。后来发现是标注不规范——有的框太松、有的类别
> 名写错。重新仔细标了一遍，同样 200 张，mAP 明显上去了。这让我体会到：**数据质量比模型
> 结构更影响结果**，这也是我为什么在这个项目里花了最多时间在数据上。"
