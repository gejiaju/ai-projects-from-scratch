# 第六阶段：面试材料整理

> 把前五个阶段的所有成果，整理成面试能直接用的材料。

## 材料清单

| 文件 | 内容 | 用途 |
|------|------|------|
| `interview-qa.md` | 14 个高频问题的 1 分钟/3 分钟版回答 | 面试问答准备 |
| `self-introduction.md` | 3 分钟版 + 10 分钟版自述 | 开场自我介绍 |
| `report/technical_report.md` | 15-20 页技术报告（六阶段汇总） | 书面材料 / 简历附件 |
| `ppt/项目总结.pptx` | 18 页项目总结 PPT | 现场展示 |
| `ppt/generate_ppt.py` | PPT 生成脚本 | 修改后重新生成 |

## 面试前检查清单（对照 CLAUDE.md）

- [x] 核心概念能用简单语言讲清（见 interview-qa.md）
- [x] "为什么选这个方法"有理由回答（每道题都有 3 分钟展开版）
- [x] 实验结果保存为清晰图表（各阶段都有 PNG 图表）
- [x] 每个仓库 README 写清"为什么做 + 怎么做"（各 phase 都有）
- [x] 失败尝试和踩坑经验记录（第三/四/五阶段都有踩坑记录）

## 5 分钟项目自述的核心线索

```
背景（EE 转 AI） → 项目一（理解原理） → 项目二（动手复现+结构图）
→ 项目三（严谨改进+负面结果） → 项目四（生成模型+部署+微调）
→ 总结（系统思维 + 独立解决问题的能力）
```

## 使用建议

1. **面试前**：把 `self-introduction.md` 的两个版本背熟，把 `interview-qa.md` 过一遍
2. **面试中**：被追问时翻 `interview-qa.md` 的 3 分钟版
3. **展示时**：PPT 第 7 页（YOLO 结构图）、第 12 页（DDPM 演变图）是亮点，主动引导老师看
