# 第五阶段 · DDPM 扩散模型（从零实现）

> 扩散模型是当前 AI 生成图片（Stable Diffusion、DALL·E）的底层原理。
> 这里从零手写一个 DDPM，在 MNIST 上训练，让它学会"从纯噪声逐步还原出手写数字"。
> 核心展示物：**噪声 → 图像 的演变过程图**，比任何损失曲线都直观。

## DDPM 原理（面试要能讲）

扩散模型分两步：

1. **前向过程（加噪）**：给一张干净图片，逐步加高斯噪声，加很多步后变成纯噪声。
   公式：`x_t = √(ᾱ_t)·x_0 + √(1-ᾱ_t)·ε`，其中 ε 是标准高斯噪声。

2. **反向过程（去噪）**：训练一个 U-Net，让它学会"从 x_t 预测出加进去的噪声 ε"。
   采样时从纯噪声出发，一步步用预测的噪声把图"洗"干净，最终得到一张新图片。

关键洞察：**加噪是固定公式（不需要学），去噪才是要学的**。训练目标就是
让网络预测的噪声 ε_θ 和真实噪声 ε 越接近越好（MSE）。

U-Net 预测噪声、逐步去噪。我在 MNIST 上训练了 20 轮，从纯高斯噪声一步步生成了手写数字。

## 面试追问准备

- **为什么用 U-Net？** 去噪是"输入一张带噪图、输出同样大小的噪声图"，是像素级预测，
  U-Net 的编码器-解码器 + skip 连接结构特别适合这种"输入输出同尺寸"的任务。
- **时间步怎么注入？** 用正弦位置编码把 t 变成向量，通过 MLP 加到每个残差块的
  特征上，让网络"知道"自己正在处理第几步的噪声。
- **和 GAN 比？** 扩散模型训练更稳定（不用对抗博弈）、生成多样性更好，但采样慢
  （要迭代几百步）。DDIM 等方法能加速采样。
