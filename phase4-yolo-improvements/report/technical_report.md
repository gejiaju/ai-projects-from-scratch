# YOLOv8 注意力机制改进与消融实验报告

> 第四阶段技术报告。核心问题：**在 YOLOv8 里加注意力模块，到底能不能提升检测精度？
> SE 和 CBAM 哪种更好？** 用严格的消融实验（控制变量）给出答案。

## 一、问题是什么

YOLOv8 的 Backbone 由 C2f 模块堆叠而成。C2f 在提取特征时，对**所有通道、所有空间位置
一视同仁**——它没有区分"哪些特征更重要"。

但在真实检测任务里，不同特征的重要程度是不同的。比如检测"安全帽"时，颜色通道可能比
纹理通道更关键；目标中心区域可能比背景更关键。如果能让网络**自动学会给重要特征加权**，
理论上精度能提升。

## 二、前人怎么做（注意力机制）

注意力机制的核心思想是"让网络自己决定该关注哪里"。目标检测里最常用两种：

### 2.1 SE（Squeeze-and-Excitation，通道注意力）

- **Squeeze**：对每个通道做全局平均池化，把一个 `H×W` 的特征图压缩成 1 个数，
  得到"每个通道的整体强度"。
- **Excitation**：用两个全连接层（先降维再升维）学出每个通道的权重（0~1），
  中间用 ReLU 引入非线性。
- **Reweight**：把权重乘回原特征图的每个通道。

效果：网络自动学会"哪些通道重要，就放大；哪些不重要，就抑制"。

### 2.2 CBAM（Convolutional Block Attention Module，通道+空间注意力）

CBAM 在 SE 基础上更进一步，做了**两级注意力**：

1. **通道注意力**：类似 SE，但同时用 max-pool 和 avg-pool 两路（SE 只用 avg-pool），
   信息更全。
2. **空间注意力**：在通道维度上做 max/avg，拼成一个 2 通道图，再用 7×7 卷积学出
   "哪些空间位置重要"的空间权重。

效果：既知道"哪些通道重要"，又知道"图上哪里重要"。

## 三、我做了什么

把 SE 和 CBAM 作为"插件"，加在 YOLOv8 的 C2f 模块后面，得到两个变体：

- **C2fSE** = C2f + SE（在 C2f 输出后加通道注意力）
- **C2fCBAM** = C2f + CBAM（在 C2f 输出后加通道+空间注意力）

关键设计：**注入式替换**。先构建 baseline，再递归把模型里的每个 C2f 就地替换成
C2fSE/C2fCBAM，保证**除了注意力模块，其他结构完全一致**。这样消融实验才公平。

（实现细节踩坑：ultralytics 的 parse_model 对 C2f 有特殊参数处理，自定义模块直接写
yaml 会参数错位报 `TypeError`。改为代码内注入后解决——这个排查过程见 experiments/ 下的
show_parse.py 和 find_register.py。）

## 四、实验设置

| 项 | 值 |
|----|-----|
| 数据集 | COCO128（128 张图，80 类） |
| 图片尺寸 | 640×640 |
| batch size | 16 |
| 轮数 | 30 |
| 优化器 | auto（SGD） |
| 随机种子 | 0（三组完全一致） |
| 设备 | RTX 5060 Laptop GPU |

**控制变量**：三组实验只改"注意力模块"这一个变量，其余全部相同。

## 五、结果

三组实验都在 COCO128 上微调 30 轮（预训练权重 yolov8n.pt 初始化），真实训练得到：

| 实验组 | 参数量 | mAP50 | 相对 baseline 提升 |
|--------|--------|-------|-------------------|
| baseline (YOLOv8n) | 3,157,200 | **80.28%** | — |
| +SE | 3,180,880 | 80.24% | -0.04% |
| +CBAM | 3,181,664 | 80.24% | -0.04% |

（对比柱状图见 `experiments/results/ablation_bar.png`，由 `plot_ablation.py` 生成。）

## 六、分析（为什么没提升）

**结论：在 COCO128 上，加 SE / CBAM 注意力没有带来提升，反而略微下降（-0.04%）。**

这是真实且值得讲的观察，原因有三：

1. **数据量太小，模型已经"吃饱了"**。COCO128 只有 128 张训练图，30 轮微调后
   baseline 已经 80% mAP，几乎把这个小数据集"背下来了"。此时加注意力没有额外
   信息可以挖掘，反而因为多了参数（+0.75%）轻微过拟合。

2. **注意力模块的优势需要更难的任务才能体现**。SE/CBAM 学的是"哪些通道/位置重要"，
   这在类别多、目标尺度变化大、背景复杂的大数据集（如完整 COCO 的 11 万张图）上
   才有用武之地。COCO128 太小、太简单，baseline 的 C2f 已经够用。

3. **注意力层是从零随机初始化、只微调 30 轮**。C2f 本体有预训练权重，但新增的
   SE/CBAM 层是随机的，30 轮（小 lr 微调）不足以让注意力层充分收敛。

## 七、结论

**"加模块 ≠ 一定有效"，效果取决于数据和任务。** 这次消融实验的正面价值在于：
用严格的对照（三组只差一个变量）证明了"在 COCO128 上注意力无效"这个结论是**可信的**，
而不是拍脑袋。如果换到更大的数据集，SE/CBAM 通常能带来 1~2 个点的 mAP 提升（这是
文献里常见的结论），只是本阶段受限于数据和算力没体现出来。
