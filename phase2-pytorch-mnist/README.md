# 第二阶段：MLP vs CNN（MNIST 手写数字识别）

> 从零手写多层感知机（MLP）和卷积神经网络（CNN），在同一套训练/评估标准下公平对比，
> 用真实实验结果回答一个面试必问题：**为什么 CNN 在图像上比 MLP 强？**

## 项目背景

深度学习处理图像，最基础的一课就是搞清楚：同样是"一堆参数搭起来的网络"，
为什么 CNN 能做视觉任务，而只有全连接层的 MLP 不行？这个项目用 MNIST
（6 万张手写数字图片）把两种网络从零实现、训练、对比，得出可以直接讲的结论。

## 方法说明

两个模型都**用 PyTorch 手写**，走**完全相同的**训练代码和超参数（学习率 0.01、
SGD+动量、batch size 128、10 轮、随机种子 42），只换模型结构——这样对比才公平。

| | MLP | CNN |
|---|---|---|
| 结构 | 拍平成 784 个数 → 全连接层×2 | 卷积层×2 + 池化×2 + 全连接层 |
| 参数量 | 109,386 | **20,490**（更少） |
| 思路 | 把图片当"一长串数字" | 用 3×3 窗口在图上滑动找局部特征 |

## 实验结果

| 模型 | 参数量 | 测试准确率 |
|------|--------|-----------|
| MLP | 109,386 | 98.02% |
| CNN | **20,490** | **99.15%** |

对比图（`results/` 目录下）：

- `loss_curve.png` — 训练损失下降曲线
- `acc_curve.png` — 测试准确率上升曲线
- `acc_bar.png` — 最终准确率柱状图

CNN 每一类数字的准确率都在 98% 以上（数字 1 最高 99.74%，数字 9 最低 98.22%）。

## 为什么 CNN 比 MLP 好？（面试 1 分钟回答）

三个原因，层层递进：

1. **参数共享**：卷积核在整张图上滑动，同一组权重到处复用，所以 CNN 参数更少
   （2 万 vs 11 万），更不容易过拟合。
2. **局部感受野**：卷积核每次只看 3×3 的一小块，能抓住"边缘、笔画、角"这些局部
   结构；而 MLP 把图片拍平，像素之间的位置关系直接丢失。
3. **平移不变性**：池化层让特征对"数字稍微挪动位置"不敏感，而 MLP 对位置很敏感。

一句话总结：**MLP 只看到了 784 个孤立的数字，CNN 看到了"有结构的图像"。**

## 如何使用

```bash
cd /mnt/f/yolo/phase2-pytorch-mnist

# 训练（首次运行会自动下载 MNIST，之后用 GPU 跑）
python3 train.py --model cnn --epochs 10
python3 train.py --model mlp --epochs 10

# 查看每个数字的准确率
python3 evaluate.py --model cnn

# 画对比图（需要两个模型都训练过）
python3 compare.py

# 单独看模型结构和参数量
python3 models.py
```

## 文件清单

| 文件 | 干什么 |
|------|--------|
| `models.py` | 手写 MLP 和 CNN 两个模型类 |
| `train.py` | 手写训练循环（前向→loss→反向→更新），保存曲线和权重 |
| `evaluate.py` | 评估模型，输出每个数字的准确率 |
| `compare.py` | 画 MLP vs CNN 对比图 |
